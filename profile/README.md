Architecture practice in Budapest.
We work with existing buildings and building physics, and we build our own tools when the usual ones fall short.

This is where those tools live.
Each one started as a fix for a problem in our own work.
We publish them so that colleagues, students and friends with the same problem can use them too.

## Tools

| | |
| --- | --- |
| [**tex-authorship**](https://github.com/odv-hu/tex-authorship) | Authorship tracking for LaTeX, in the spirit of iA Writer. A VS Code extension and a LuaLaTeX package that mark which parts of a text you wrote yourself and which came from elsewhere, such as an AI. |
| [**bim**](https://github.com/odv-hu/bim) | ÉKTR classification XML for Navisworks, first shared with students of the BIM specialist engineer course at BME. |

Issues and pull requests are welcome.

Architecture practice in Budapest, somewhere between design and research.
We work increasingly with existing buildings, modelling and studying them through building physics.
We have started building our own tools to make that work easier.

This is where those tools live.
Each one started as a fix for a problem in our own work.
We publish them so that colleagues, students and friends with a similar problem can use them too.

## Tools

| | |
| --- | --- |
| [**tex-authorship**](https://github.com/odv-hu/tex-authorship) | Authorship tracking for LaTeX, in the spirit of iA Writer. A VS Code extension and a LuaLaTeX package that mark which parts of a text you wrote yourself and which came from elsewhere: a co-author, a quote from a dusty library book or a paragraph pasted from your favourite AI. |
| [**bim**](https://github.com/odv-hu/bim) | Currently contains the Hungarian ÉKTR classification XML for Navisworks, shared with students of the BIM specialist engineer course at BME. |

Issues and pull requests are welcome.
